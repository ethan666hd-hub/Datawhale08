日常对话与通用助手

豆包 / ChatGPT / Claude / DeepSeek

大部分人第一次用 AI，都是从问问题、写文案、改材料和语音聊天开始。这四个都值得放进清单。

豆包

中文日常问答、写文案和语音聊天。国内使用方便，免费功能够普通人上手。

ChatGPT

探索陌生领域和处理综合任务。文字、图片、文件可以放在同一段对话里继续追问。

Claude

写作、分析和长文本处理。手里已经有一批材料，需要梳理结构和表达时更对路。

DeepSeek

中文推理和成本敏感的任务。适合希望快速开始、再根据结果继续追问的人。

使用心法

别把它当搜索引擎，把它当你的实习生用。这是给谁看的？要啥风格？字数多少？必须包含哪些点？交代得越清楚，出来的东西越能用。

办公与文档

资料跨文档、网页和本地文件

豆包工作

适合 PPT、文档、表格、多来源调研、定时报告和本地文件操作。

资料已经在协作空间里

飞书智能伙伴 / Notion AI

少一次复制、上传和权限迁移，直接在现有文档里整理、写作和交付。

权限边界

能操作本地文件和网页的产品，权限比普通聊天更高。第一次使用从单独文件夹开始，发送、提交和删除保留人工确认。

搜索与研究

公开网页

秘塔 AI 搜索

查陌生概念、公司或行业，收集公开资料并保留来源。

已有材料

Kimi K3

读会议记录、报告、论文和合同，再做提取、整理和复杂知识工作。

→
最终结果

可复查的研究稿

结论标出原文位置，关键事实回到来源核对。

带链接不等于自动可信

至少打开两到三个来源，核对发布日期、原文语境和数据口径。合同分析只能用于初步提取，不能替代律师。

图片、视频与设计交付

图片创作

即梦 / Midjourney / GPT-Image 2

即梦适合中文创作和分镜；Midjourney 适合风格探索；GPT-Image 2 适合在对话里反复改图。

封面 / 人物 / 分镜
视频生成

Seedance 2.5 / MiniMax H3 / 可灵 / Vidu

用同一段脚本和参考素材生成短样片，比较人物一致性、动作、声音和可编辑性。

脚本 / 画面 / 声音
最终剪辑

剪映

生成不是结束。字幕、节奏、素材替换、配音和最终发布，仍然回到剪映完成。

设计交付

Lovart / MiniMax Design

海报、品牌和电商物料用 Lovart；脚本、图片、视频和声音共同推进，用 MiniMax Design。

工作台、Agent 与编程

Cherry Studio

把多个模型放进一个桌面工作台

适合已经明确需要管理多个模型、API 或知识库的人。本地存储不等于模型完全在本地，调用云端 API 时内容仍会交给服务商。

扣子

跨设备、定时任务与多 Agent

扣子没有消失，也没有改名成豆包工作。它更集中在跨设备执行、多 Agent 协作、长时间任务和团队沉淀。

编程须按基础分层

  1. 纯小白秒哒 / 扣子编程
  2. 能看懂简单代码Cursor / TRAE
  3. 理解项目、测试和 GitCodex / Claude Code / Gemini CLI / Kimi Code
  4. 团队或复杂项目CCB + Superpowers

工具选择的心法

  1. 按真实任务选工具不要在工具本身上投入太多，选一个顺手的深耕。
  2. 把需求表达清楚给谁看、想得到什么、有哪些限制、怎么才算完成。
  3. 关注端到端产品工作流被模型内化，仍然是最值得抓住的方向。
